How do I configure my browser if I'm using Internet Explorer for Macintosh?


Step 1. Open the Control Panel "Internet" or "Internet Config" (name differs by OS version).

Step 2. Click File Mappings.

Step 3. Click on the Add button and fill in the following:
Name: MPEG Audio
Extension: .mp3
MIME Type: audio/x-mpeg

Step 4. Select Binary Data

Step 5. Check Post Process and click on the None button, then find the file name of the new player you want to default to.

Step 6. Click OK.

Step 7. Now you must change your default setting for streaming MP3s. Click on the Add button and fill in the following:
Name: Streaming MPEG Audio
Extension: .m3u
MIME Type: audio/x-mpegurl

Step 8. Select Binary Data
Check Post Process and click on the None button, then find the file name of the new player you want to default to.

Step 9. Click OK.

Step 10. Under File, select Save to retain your settings.

Step 11. Quit Internet Config.

Step 12. Quit and restart Internet Explorer.


Still having problems with your default settings?

Make sure you closed and reopened your browser.
Make sure you've edited all file types with MP3 and M3U extensions.
Try contacting your player's company web site.
